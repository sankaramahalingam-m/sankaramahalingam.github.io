# Dr. M. Sankara Mahalingam — Academic & Research Website

Personal academic portfolio website designed for GitHub Pages.

## Files

- `index.html` — main website
- `style.css` — responsive design and styling
- `script.js` — mobile navigation and footer year
- `assets/profile.jpg` — professional profile image

## GitHub Pages

1. Create a repository named `<your-github-username>.github.io`.
2. Upload all files and the `assets` folder.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Save and wait for GitHub Pages to publish.

## Important customization

Before publishing, replace the placeholder profile/social links in `index.html` with the exact URLs for:
- LinkedIn
- ORCID
- Google Scholar
- Scopus
- Institutional email

Also update publication DOI links when available.
